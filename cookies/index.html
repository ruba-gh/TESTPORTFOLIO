Cookie Policy

Configured behavior

This site’s own code does not set analytics cookies, advertising cookies, personalization cookies or tracking identifiers. It includes no Google Analytics, Meta Pixel, advertising SDK, fingerprinting code, social-media embeds or video embeds.

Why there is no cookie banner

Because this build does not load non-essential tracking or advertising technology, it intentionally does not display an ornamental consent banner. A banner should only be added if the deployed site actually introduces technology that requires a consent choice.

Hosting and security

The production package is configured for Netlify. Hosting and security infrastructure may use strictly necessary technical mechanisms to deliver and protect the site. Those mechanisms should be re-checked against the deployed host’s current documentation before publication.

If the setup changes

If analytics, advertising, embedded media or another non-essential technology is added, the site must first review whether consent is required, update this policy and block applicable scripts until the user has made the required choice. Last updated: 6 September 2026.
